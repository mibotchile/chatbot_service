Instalación · Widget embebible

Poné el chat de Ada en tu sitio web

Copiá una línea de código y pegala antes de </body> en tu web. El chat flotante de Ada aparece abajo a la derecha. Funciona en cualquier sitio: el widget se aísla en un Shadow DOM, así tus estilos no lo rompen y los suyos no tocan tu página.

1. Pegá este snippet

<script src="__SRC__" data-tenant="prestamype" async></script>

Para producción: avisanos los dominios reales de tu web (ej. https://prestamype.com) para habilitarlos. Mientras tanto el widget funciona desde demos.mibot.cl y desde localhost (cualquier puerto) para que lo pruebes localmente.

2. Opciones (atributos del <script>)

AtributoPara qué sirve
data-tenantIdentifica tu marca/configuración. Requerido. Aquí: prestamype.
data-ctOpcional. Token de campaña para identidad por enlace (ej. campañas de cobranza).
data-apiOpcional. Sobrescribe la URL base del backend (por defecto se deriva del src).

3. Probalo acá mismo

Esta página simula tu sitio: el snippet de arriba ya está cargado abajo. Buscá el botón verde flotante en la esquina inferior derecha, abrilo y escribí un DNI de prueba (ej. 44218903) para identificarte.
